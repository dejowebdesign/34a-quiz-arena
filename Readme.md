# 34A Quiz Arena

Multiplayer-Quizshow zur Vorbereitung auf die Sachkundeprüfung nach § 34a GewO.

## Technologie

- React und TypeScript
- Node.js und Socket.IO
- SQLite
- Docker Compose

> Hinweis: Die Quiz Arena dient der Prüfungsvorbereitung. Das spielinterne Leistungszertifikat ist kein amtlicher Nachweis der Sachkundeprüfung.
